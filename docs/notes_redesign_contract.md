## 要做的（数据模型 + 流程）
1. **画的与匹配的分开存**：每笔加 `drawn`（画完那一刻的原样：页面版本号、pts、frame、anchor、orig、设备 UA、时间），**此后任何代码都不许改 `drawn`**；显示用的 `anchor`/`cover` 是匹配结果，可以重算。用户移动/删除一笔才算「画」的改动（移动 = 新 drawn）。
2. **页面带版本号**：build_site 生成页面时嵌入页面版本号（内容哈希或构建 id），笔画下时把版本号写进 `drawn.page`；每次保存笔记文件记录 `savedOn`（页面版本号）。
3. **圈住内容（cover）只在用户设备上算**：画笔时当场算（已有 anchorForStroke 的 cover 逻辑）；老的 308 笔在用户打开快照页（各自 drawn 的那一版）时由设备算出 cover 写入匹配字段（快照页目前只读，要加一个用户点按钮才写回的「确认并保存」）。
4. **跟着内容走**：当前页面上按 cover 找（规则见上面用户原话；已实现在 annotate.py findCover/findCoverGlyph，可复用）；内容没了就**隐藏**（不灰）；**任何页面上都不许出现灰色**（`.orphan` 一律不显示）。
5. **快照**：每一次主动画笔结束时的「笔记 + 页面」自动可复现（工具 `repair_notes_positions.py --snapshots` 已有，改成从 `drawn` 生成）。
