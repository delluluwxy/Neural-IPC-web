研究目标

  • 接触时物体在接触区产生局部变形，正是这一局部变形保证两物体互不穿透；变形中储存的弹性能即接触能量。
  • 全分辨率 IPC + FEM 可精确求解，但自由度多、计算慢。
  • 本项目：仿真只保留少量降阶自由度（刚体、仿射或少数模态），接触区局部变形对应的能量由神经网络学习。

\[U_c(z)=\min_{w}\ \Pi(\Phi z+\Psi w)-\Pi(\Phi z)\]

  • z：降阶自由度，即仿真器实际求解的少量变量。
  • Φz：仅由降阶自由度表示的位形，接触时与对方相互穿透。
  • Ψw：接触区的局部修正变形，w 为其系数；\(\min_w\) 表示在无穿透条件下对局部变形取能量最小（静态凝聚）。
  • Π：总弹性势能。
  • \(U_c\) 即消除穿透所需的额外弹性能（凝聚接触势），由网络学习；接触力由其梯度给出，是保守力。
  • 训练标签由 IPC + 精细 FEM 的准静态解给出：IPC（Incremental Potential Contact）以势垒保证全程无穿透。

Hydroelastic 接触模型

  • Genesis 中的 hydroelastic 接触由三部分组成：Elandt 2019 的压力场模型给出接触力，Masterjohn 2022 将其离散为点接触，SAP 负责求解。

Elandt 2019：压力场接触模型

  • 每个物体内部预定义一个标量压力场，表面为 0，向内部单调增大。
  • 两物体按刚体几何直接重叠、不计变形；重叠区内两侧压力相等的等压面即接触面，压力在其上积分得到接触力。

\[p_0=E\,\varepsilon,\qquad F=\int_S p_0\,dA\]

  • ε：归一化穿透深度（表面为 0，中轴为 1）。
  • E：hydroelastic 模量，为用户指定的模型参数，与材料杨氏模量无直接对应。
  • 穿透越深，压力与接触面积同时增大，接触力随之增大。

Masterjohn 2022：接触面片的速度层离散

  • 将接触面上每个多边形面片等效为一个柔性点接触（线性弹簧），从而接入固定步长的速度层求解器，实现实时仿真。

\[k=g\,A,\qquad \phi_0=-\frac{p}{g}\]

  • A：面片面积；p：面片形心压力；g：两侧压力沿法向的等效梯度（串联）。
  • 面积越大、压力梯度越大，等效刚度越大；静止时面片合力等于面积 × 形心压力，与连续模型一致。

SAP 2022：无约束凸优化求解器

  • 将每个时间步的柔性接触问题写成仅含速度、无约束、强凸的最小化问题，解唯一，牛顿法稳定收敛。

\[\min_{\mathbf v}\ \tfrac12\|\mathbf v-\mathbf v^*\|_A^2+\ell_{\text{接触}}(\mathbf v)\]

  • v：下一时间步的速度；v*：无接触时的自由运动速度。
  • 第一项为偏离自由运动的惯性代价，第二项为阻止法向压入的接触项。

Genesis 实现与官方测试

  • Genesis 的 hydroelastic 即上述三者的组合；刚体共用一个全局 hydroelastic 模量（默认 1e8 Pa），与材料杨氏模量不联动。

模型假设

  • 每点的压力只取决于该点自身的穿透深度，近似于 Winkler 地基（一组互不耦合的弹簧）；真实弹性体中各点通过连续介质相互耦合。第 5 部分的实验即针对这一差异设计。

神经网络接触模型

  • 现有方法学习位移修正或刚体运动，不学习接触能量，也不保证无穿透；本项目学习接触能量，接触力由能量梯度给出。

Romero 2021：降阶子空间 + 学习接触区位移修正

\[\mathbf x(\mathbf q)=\mathbf U\mathbf q+\mathbf F(\mathbf q)\,\mathbf r(\mathbf q)\]

  • Uq：控制柄（handle）插值得到的子空间位形；r：网络预测的局部位移修正；F：形变梯度，将修正变换到当前位形。
  • 与本项目思路最接近（降阶自由度 + 学习局部变形），区别在于其学习位移而非能量。

Romero 2022：在碰撞体坐标系中学习接触变形

\[u(\bar x)=\mathbf T(\mathbf z)\,r(\bar z),\qquad \bar z=\mathbf T(\mathbf z)^{-1}\tilde x(\bar x)\]

  • T(z)：碰撞体的刚体变换；z̄：材料点在碰撞体坐标系中的位置；r：该坐标系下预测的局部位移。
  • 在碰撞体坐标系下变形场更平滑，所需训练数据显著减少。

Romero 2023：基于局部 SDF 描述子泛化到未见碰撞体

\[r_{\text{local}}=\mathbb N\big(\hat\phi(x),\,W(\bar x)\,R^{-1}T^{-1}(q-x)\big)\]

  • φ̂：兴趣点邻域内 65 个采样点的有符号距离值，描述碰撞体的局部几何。
  • 对未见几何的泛化，与本项目「单一模型覆盖多种形状」的目标一致。

RigidFormer：以 Transformer 预测多刚体运动

\[\mathbf x_{t+1}=f_\theta(\mathbf x_{t-1},\mathbf x_t,\Delta t)\]

  • 由前两帧预测下一帧；每个物体预测 4 个锚点的加速度，再投影为刚体变换。
  • 替代整个求解器，无能量表述，物体间不保证无穿透；本项目保留仿真器，仅增加一项接触能量。

NeuralIPC 代码现状

  • 已有：BEM（边界元）与有限应变 FEM 生成的标签、凝聚接触势网络，以及多接触区耦合。

\[U=\sum_k U_k(\delta_k)\;-\;\sum_{k\lt l}\mathrm{softplus}(\mathrm{NN})\,\sqrt{U_kU_l}\,\frac{L}{r_{kl}},\qquad \delta_k=\max\big(0,\,-\min\text{gap}_k\big)\]

  • 每个接触区先由几何计算有向间隙得到穿透深度 δ，网络仅输出该区能量 \(U_k\)；无接触时 δ = 0，能量严格为 0。
  • 同一基底上相邻接触区相互预压、整体变软，故减去耦合项；两区距离 r 越小，修正越大。
  • BEM 标签与 Hertz 误差 < 0.1%；网络学到的幂次中位数 2.47（Hertz 为 2.5）。
  • 多接触区不可直接叠加：2 / 3 个接触区直接相加高估 27.8% / 54.9%，引入耦合后为 6.1% / 6.5%。
  • 准静态接触势适用于低速冲击：冲击速度为波速的 1.5% 时误差 0.4%，30% 时达 212%（遗漏振动能）。
  • 尚缺：libuipc 生成的 3D IPC 标签尚未接入训练。其球压算例在网格加密下为 1.312 → 1.235 → 1.208，尚未收敛，原因见第 6 部分；材料泛化、速度评测与演示尚未开展。

与 hydroelastic 的对比实验设计

  • 以弹性力学解析解为裁判，不使用任何一方的仿真结果作为真值。
  • 以力的比值为主判据：同一物体、同一压深，仅改变一个几何参数，比较力的变化倍数；比值中 hydroelastic 模量被约去，不能通过调参弥补。
  • hydroelastic 模量仅用训练数据拟合一次，之后固定；若对每个实验单独调参，任一单例都可拟合，但不具预测性。

E1 球半径加倍：Hertz 解 ×1.41，hydroelastic ×2

\[F_{\text{Hertz}}=\tfrac{4}{3}E^{*}R^{1/2}\delta^{3/2}\]

  • Hertz：接触半径增大但平均压力降低，力按 √R 增长。
  • hydroelastic：力与重叠面积成正比，按 R 增长，与压力映射形式无关。

E2 平底圆柱压头半径 ×2、×4：解析解 ×2、×4，hydroelastic ×4、×16

\[F_{\text{Boussinesq}}=2E^{*}a\,\delta,\qquad F_{\text{hydro}}=\pi a^{2}\,p(\delta)\]

  • 解析解：变形影响深度随压头半径 a 增大，同一压深下应变减小，力与 a 成正比。
  • hydroelastic：底面各点穿透相同，力 = 面积 × 压力，按 a² 增长。

E3 同一刚体上两个凸台间距减小：解析解每个凸台力减小 6–14%，hydroelastic 不变

\[F_{\text{每个凸台}}=\frac{2E^{*}a\,\delta}{1+2a/(\pi L)}\]

  • 解析解：相邻凸台使基底整体下沉，自身变形减小；L 为中心距，L = 4a 时减小约 14%，10a 时约 6%。
  • hydroelastic：各面片独立计算，与 L 无关。

E4 粘结于刚性基底的近不可压薄层：球半径加倍，解析解趋近 ×4，hydroelastic ×2

\[F_{\text{不可压}}=\frac{\pi}{2}E^{*}\frac{R^{2}\delta^{3}}{b^{3}}\]

  • 解析解：近不可压材料只能侧向挤出，接触越宽挤出路径越长，力按 R² 增长；b 为层厚。
  • hydroelastic：仍按 R 增长。可压缩情形（ν = 0.3）两者均为 ×2，作对照。

E5 降阶表示自身可变形时，hydroelastic 重复计入柔度

  • 解析解：仿射体（可整体平移、旋转、均匀拉伸和剪切）已承担部分变形，正确的接触能量应相应减小。
  • hydroelastic：只依赖材料与几何，柔度被计入两次，力偏小；supervisor 数据中该偏差随长细比增大，线弹性 1% → 10%，有限应变 7% → 17%。
  • 本项目学习的是扣除降阶表示已储存能量后的残差，不存在这一问题。

前提：IPC 标签的收敛性

  • 以 supervisor 造标签的球压算例与 Hertz 解对比：标签能量 / Hertz 能量，1 表示一致。

设置：刚性球（半径 1）竖直压进底面固定的软块（E = 1e5，ν = 0.3），无摩擦、无重力，压深 0.004–0.024，每个压深求准静态平衡后计算块的弹性能。原来：块宽 2.4、高 1.2，接触区网格 0.025，势垒距离 \(\hat d\) = 1e-3，球面细分 4 次。修正后：\(\hat d\) 三档外推到 0，球面细分 7 次，块半宽 2.4 / 4.8 外推到无限大，网格 0.0125 / 0.00625 外推到 0，材料参数按求解器实际使用的能量改写

  • 原设置结果为 1.46，其中包含两项方向相反、部分抵消的误差。

\[B(d)=\kappa\,\big(d^2-\hat d^{\,2}\big)^2\Big[\ln\frac{d^2}{\hat d^{\,2}}\Big]^2\quad (d\lt\hat d)\]

  • IPC 势垒距离 \(\hat d\) 使能量偏大：两表面距离小于 \(\hat d\) 即产生斥力（距离趋于 0 时势能趋于无穷，保证无穿透），等效于接触提前发生；偏差近似与 \(\hat d\) 成正比，可外推至 \(\hat d\) → 0。
  • 压头球面离散过粗使能量偏小：面片尺寸大于 Hertz 接触半径，球底近似为尖点；细分 7 次后收敛。
  • 新版 libuipc 的材料参数换算有误，实际杨氏模量偏大 24%：单轴拉伸实测确认；改写内部参数后恢复设定值。
  • 修正后标签与 Hertz 一致：小压深 0.99，大压深 1.01。
  • 在本算例的压深范围内，Hertz 解自身的近似误差 < 0.2%：由不经过 IPC 的独立有限元验证，可作为裁判。

设置：独立有限元：supervisor 的轴对称有限元程序（不经过 IPC，无势垒距离），圆柱块半径 = 高 = 2.4 → 19.2，两种网格；按 Hertz 的全部假设算一遍、按标签实际使用的材料和真实球面再算一遍，都按块大小外推到无限大
